# archive/

Исторические материалы, которые больше не участвуют в сборке, тестах и
импортах, но удалять которые жалко: они фиксируют путь проекта.

| Файл | Что это | Почему здесь |
| --- | --- | --- |
| `legacy/olma_upgrade_addon.py` | Одноразовый скрипт-апгрейд OLMA (`olma/learn.py`, `olma/github.py`, правки `olma/cli.py`) | Не имеет машиночитаемого расширения в исходном виде, ни на что не ссылается. Апгрейд уже применён в `mountfile/olma/`, скрипт оставлен как история. |

Правила для этого каталога:

- файлы отсюда **не импортируются** рабочим кодом;
- новые записи сюда добавляются только через `git mv`, чтобы история файла не терялась;
- каталог исключён из статистики языков через `.gitattributes`.
