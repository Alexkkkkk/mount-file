# archive/

Исторические материалы, которые больше не участвуют в сборке, тестах и
импортах, но удалять которые жалко: они фиксируют путь проекта.

| Файл | Что это | Почему здесь |
| --- | --- | --- |
| `legacy/olma_upgrade_addon.py` | Одноразовый скрипт-апгрейд OLMA (`olma/learn.py`, `olma/github.py`, правки `olma/cli.py`) | Не имеет машиночитаемого расширения в исходном виде, ни на что не ссылается. Апгрейд уже применён в `mountfile/olma/`, скрипт оставлен как история. |
| `legacy/WORK_REPORT.md` | Отчёт о разовом аудите кодовой базы (состояние на версию 1.81.0) | Разовый отчёт о состоянии проекта на момент аудита; цифры и версии давно устарели, в сборку, тесты и документацию не входит, ни на что не ссылается. |
| `legacy/mountfile-fixes.patch` | Уже применённый патч (rw-v2 FAT32 fixture, smoke startup, README v1.81.0) | Патч полностью вошёл в историю `main`: обратное применение (`git apply --check --reverse`) конфликтует, то есть неопубликованной работы в нём нет. Оставлен как историческая справка. |
| `legacy/mountfile-audit-ntfs-followup.md` | Отчёт о функциональном аудите NTFS (ветка `fix/full-functional-audit-2026-11-05`) | Разовый отчёт о завершённой итерации аудита; описанные исправления уже в коде, ни на что не ссылается. |

Правила для этого каталога:

- файлы отсюда **не импортируются** рабочим кодом;
- новые записи сюда добавляются только через `git mv`, чтобы история файла не терялась;
- каталог исключён из статистики языков через `.gitattributes`.
