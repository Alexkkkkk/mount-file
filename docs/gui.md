# GUI

## Основное приложение

Запустите:

```bash
python main.py
python main.py path/to/image.img
```

Нажмите **Открыть образ** на панели инструментов или `Ctrl+O`, затем выберите
том в списке источников левой панели. Двойной щелчок открывает каталог, а файл — по типу: `.txt`, `.log`, `.ini`,
`.csv`, `.md`, `.json`, `.xml` и другие текстовые файлы уходят в системный
редактор (**Блокнот** на Windows), всё остальное показывается в HEX-просмотре
(клавиша `F3`). `F5` копирует выбранные файлы в другую панель: из образа на
локальный диск или с локального диска в доступный для записи образ. `F7`
создаёт папку; переименование и удаление используют тот же
встроенный FAT32-движок.

Интерфейс двухпанельный: вкладки каталогов, отметка файлов, массовые операции,
светлая/тёмная тема и журнал. Если выбранный том не открывается, приложение
может запустить авто-подбор; тот же режим доступен через **Инструменты →
Подобрать том автоматически…**.

Синяя рамка показывает активную панель. В её шапке явно указан источник и
режим доступа: **Не открыт**, **Только чтение**, **Запись доступна** или
**Локальный диск**. Недоступные действия отключены и объясняют причину в
подсказке. `F6` перемещает только из локальной панели; извлечение из образа
выполняется через `F5` и не удаляет исходные данные.

Поле **Фильтр по имени** (`Ctrl+F`) отбирает файлы только в текущем каталоге,
без учёта регистра. Это не поиск по содержимому или всему образу. Очистите
поле крестиком, чтобы вернуть весь список. Скрытые фильтром отметки снимаются,
а `Ctrl+A` отмечает только видимые файлы. При смене каталога, вкладки или тома
фильтр и отметки сбрасываются, чтобы одноимённый файл в другом месте случайно
не попал в массовую операцию. Множественное выделение мышью также используется
для копирования, перемещения и удаления; отметки `Space` имеют приоритет.

В небольшом окне второстепенные колонки автоматически скрываются, оставляя
место для имени файла. Полные значения доступны в подсказках в видимых ячейках;
увеличьте окно, чтобы вернуть дату и атрибуты. Светлая и тёмная темы сохраняют
одинаковую структуру и заметные состояния фокуса.

Перед заменой существующих локальных объектов приложение показывает список
конфликтов; безопасный выбор по умолчанию — **Нет**. Копирование в ту же папку
и копирование папки в саму себя блокируются. Локальное удаление выполняется
**навсегда, без корзины** и требует отдельного подтверждения.

В меню **Инструменты → DFIR triage (только чтение)…** доступны SHA-256
образа, ограниченный raw-поиск по строке/regex с byte offset и импорт timeline
CSV с консервативной проверкой timestomp. Диалог не изменяет исходный образ.
Это triage-слой, а не полноценный filesystem-aware collector, YARA scanner,
carver или chain-of-custody система.

!!! warning "Запись изменяет файл образа"
    Импорт, создание каталога, переименование и удаление не являются
    read-only операциями. Закройте образ в других программах, сохраните копию
    и только затем подтверждайте действие.

## Полезные клавиши

| Клавиша | Действие |
|---|---|
| `Enter` / двойной щелчок | открыть каталог; текстовый файл — в Блокноте, остальное — HEX-просмотр |
| `Backspace` | каталог выше |
| `Space` / `Insert` | отметить файл |
| `Tab` / `Ctrl+U` | другая панель / поменять панели |
| `Ctrl+T` / `Ctrl+W` | создать / закрыть вкладку |
| `Enter` / `F3` | текстовые файлы — в системном редакторе; остальное — HEX |
| `F4` | текст в образе — встроенная правка с записью; локальный текст — системный редактор |
| `F5` / `F6` | копирование / перемещение между панелями |
| `F7` / `F8` | создать каталог / удаление |
| `Ctrl+O` / `Ctrl+R` | открыть образ / обновить |
| `Ctrl+I` | добавить файл в AI-анализ |
| `Ctrl+F` | фильтр имён текущего каталога |
| `F9` | скрыть / вернуть меню |
| `F11` | полный экран |

`F4` редактирует текстовые файлы до 2 MiB (`ini`, `cfg`, `txt`, `log`, `json`,
`xml`, `csv`, `yaml`, `md`) и сохраняет исходную UTF-8 или CP1251 кодировку и
переводы строк. Для файлов в образе требуется writer: FAT32 поддерживается
встроенно, ext2/3/4 — только если команда `debugfs` доступна в `PATH`. Перед
записью приложение создаёт новую резервную копию образа рядом с ним; отказ от
копии отменяет запись. Для ext-записи сначала изменяется временная копия раздела,
затем данные проверяются чтением назад. Иные файловые системы остаются только
для чтения. В ext-записи допускаются только простые ASCII-имена без пробелов и
управляющих/командных символов; остальные пути будут безопасно отклонены.

При открытии текстового файла через `Enter` или `F3` из образа Mount File
создаёт временную копию и запускает системный редактор (на Windows —
Блокнот). Окно подтверждения в Mount File просит сначала сохранить копию и
закрыть редактор, затем вернуться и нажать **«Да»** для проверки и импорта.
Отмена или **«Нет»** оставляет образ без изменений. Перед записью создаётся
резервная копия; если исходный файл в образе изменился параллельно, импорт
отклоняется, чтобы не затереть эти изменения.

Тема, размер шрифта и видимость журнала настраиваются в **Конфигурация →
Настройки**. GUI при старте проверяет GitHub Releases в фоне; отсутствие сети
не должно блокировать работу. Для запрета проверки задайте
`MOUNTFILE_NO_UPDATE=1`.

## Отдельный `mountfile.py`

Это другой, одностраничный инструмент: он монтирует `.img`, `.iso`, `.bin`,
`.raw`, `.vhd` или `.vhdx` средствами операционной системы. Он не использует
`pytsk3`, не требует сети и не является заменой основному файловому менеджеру.

```bash
python mountfile.py                 # GUI
python mountfile.py dump.img --to /mnt/x
python mountfile.py dump.img --open
python mountfile.py --list
python mountfile.py --unmount /mnt/x
```

Механизм зависит от ОС: Linux — `udisksctl` или `mount -o loop,ro`, macOS —
`hdiutil`, Windows — PowerShell `Mount-DiskImage` для ISO/VHD/VHDX. Нужные
права и поддержка конкретного формата определяются ОС; приложение не обещает
монтирование любого raw-дампа. Для отдельного инструмента состояние и журнал
хранятся в каталоге настроек пользователя.
