# Установка компонентов MountFile на Windows

Распакуйте весь ZIP в обычную папку и дважды щёлкните `install-components.bat`.
Python для этого не нужен. Не запускайте BAT непосредственно внутри ZIP.

Установщик проверяет `debugfs` для записи ext2/3/4 и ImDisk для записи
NTFS/exFAT/FAT12/16. Если Windows попросит разрешение администратора, подтвердите
его. Если потребуется перезагрузка, выполните её самостоятельно и ещё раз
запустите тот же BAT. Затем перезапустите MountFile и переоткройте образ.
Для записи через ImDisk запускайте сам MountFile от имени администратора.

Если у вас уже работает Debian/Ubuntu в WSL, установщик добавит туда пакет
`e2fsprogs`. Иначе он включит WSL2 и импортирует служебный Ubuntu-дистрибутив
`MountFileTools`; загрузка занимает около 325 МБ, установленная система требует
дополнительного свободного места. Нужны Windows 10 сборка 19041+ или Windows 11,
интернет и поддержка виртуализации для нового WSL2. Дистрибутив по умолчанию не
переключается, существующие дистрибутивы не удаляются. В новой версии MountFile
отдельный `MountFileTools` обнаруживается автоматически.

Для старых EXE: при первом создании WSL-дистрибутива он становится первым
дистрибутивом по умолчанию и обнаруживается старым MountFile. Существующий
Debian/Ubuntu также поддерживается. Если до установки уже был другой, не
Debian/Ubuntu дистрибутив по умолчанию, обновите MountFile до версии с поддержкой
`MountFileTools`: старый EXE не умеет искать debugfs в отдельном дистрибутиве.
Установщик не переключает ваш WSL default ради совместимости со старым EXE.

Для установки только ext-компонентов откройте PowerShell в распакованной папке:

```powershell
.\install-components.bat -SkipImDisk
```

Для предварительного просмотра без изменений:

```powershell
.\install-components.bat -DryRun
```

Ubuntu rootfs загружается с официального сайта и проверяется по SHA-256.
ImDisk загружается с официального сайта автора и запускается только после
проверки Authenticode и издателя. При ошибке установщик остановится, а не
объявит успех. Журналы доступны в `%LOCALAPPDATA%\MountFile\logs`.

Установщик не монтирует, не форматирует и не изменяет пользовательские образы
или физические диски. Он не отменяет защиту записи и требование резервной копии.
Он также не устанавливает Python-библиотеки, AI-модели или серверы: для полной
установки исходников используйте `install.bat` из репозитория.
